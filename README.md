# 🎵 Mood-Based Food and Music Recommendation System 🍔

An intelligent recommendation system that detects user mood from text input using Machine Learning and provides personalized food and music recommendations.

The system combines NLP-based mood analysis, FastAPI backend services, and a React frontend to create an interactive recommendation experience.

---

# 🚀 Features

- 🧠 Mood detection using Machine Learning
- 🍔 Personalized food recommendations
- 🎵 Music recommendations based on mood
- ⚡ FastAPI backend APIs
- 💻 Interactive React frontend
- 🔄 Real-time recommendation system
- 📊 Clean and responsive UI

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Nakshatra2410/mood-food-music-recommender.git
cd mood-food-music-recommender
```

---

## 2️⃣ Backend Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

Run backend server:

```bash
uvicorn backend.main:app --reload
```

Backend runs on:
```bash
http://127.0.0.1:8000
```

---

## 3️⃣ Frontend Setup

Move to frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start frontend:

```bash
npm start
```

Frontend runs on:
```bash
http://localhost:3000
```

---

# 🧠 How It Works

1. User enters text describing their mood.
2. Machine Learning model analyzes the text.
3. Mood is predicted.
4. System recommends:
   - 🍔 Food items
   - 🎵 Music
5. Recommendations are displayed on the frontend.
